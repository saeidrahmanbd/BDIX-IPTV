What is an M3U IPTV playlist?

An M3U playlist is a text file that organizes media stream references and channel information for a compatible player. It is not a video-hosting service. BDIX-IPTV publishes playlist files, channel metadata and links to available stream endpoints; actual playback depends on the stream provider, your network and the app you use.

The main Bangladesh and India collection is intended for viewers looking for Bangladeshi IPTV, Bangla TV and Indian channels in one M3U file. The separate International collection follows the project's published country and genre rules.

How to use an M3U URL

  1. Copy the playlist URL you want.
  2. Open VLC, Kodi, TiviMate, XCIPTV, IPTV Smarters or another M3U-compatible player.
  3. Choose the option to add a playlist by URL, paste the link, save and refresh.

The exact menu name differs between apps and devices.

M3U playlist troubleshooting

  • Playlist does not load: check that the full M3U URL was copied, that your player supports adding a playlist by URL, and that the device has an internet connection.
  • Some channels do not play: a playlist can only reference streams supplied by their respective providers. A stream may be unavailable, geo-restricted or changed without notice.
  • Programme guide is empty: add the XMLTV EPG URL separately if your player requires a separate guide source. EPG coverage depends on matching schedule data being available.
  • Playlist categories look outdated: refresh or reload the M3U source in your player so it retrieves the current playlist file.

XMLTV EPG guide

Use the public BDIX-IPTV XMLTV EPG file in an EPG-compatible player. The guide is refreshed and published after generation, freshness and quality checks pass.

About BDIX and stream availability

BDIX-IPTV is a BDIX-focused playlist project, but individual channel streams may be hosted by different providers. The project does not guarantee that every URL is BDIX-routed, available through every ISP, or continuously online. It does not host the channels or video itself.

See the GitHub source repository for the playlist files, metadata, local logo assets, EPG documentation and maintenance reports.
