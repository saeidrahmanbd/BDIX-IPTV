# BDIX FTP Server Tester

Android app for testing a curated catalog of Bangladesh BDIX FTP/media endpoints.

Features: concurrent reachability scanning; Working / Not working / No response / Testing filters; Live TV / Movies filters; clickable working endpoints; five-second connect timeout; no media downloads during scanning.

A Working result means TCP connection succeeded and a server greeting may have been received. It does not guarantee anonymous login, directory browsing, or playback.
