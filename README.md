## Getting Started

1. Copy the playlist URL from the table above.
2. Open an M3U-compatible player, such as XCIPTV, TiviMate, VLC, IPTV Smarters or Kodi.
3. Add the URL as a remote M3U playlist and refresh the channel list.

The playlists are updated through repository maintenance workflows. Stream availability can vary by provider, location and time.
