# EPG setup, mapping, and publication status

## Current pipeline

The shared XMLTV guide is generated by the repository's **IPTV Playlist Update** maintenance workflow. The mapping/coverage script audits primary channel identities across all three playlists:

- `BDIX-Playlist.m3u`
- `IPTV-Playlist.m3u`

The generator writes `epg/epg.xml`. All three playlist headers should reference this published location:

`https://raw.githubusercontent.com/saeidrahmanbd/BDIX-IPTV/main/epg/epg.xml`

Coverage reports are written to `reports/epg-coverage.md` and `reports/epg-three-playlist-audit.md`; identity-to-source mappings live in `reports/epg-india-channel-mapping.csv`.

## Mapping safeguards

- Keep each playlist's `tvg-id` unchanged. For a known channel represented by different IDs in separate playlists, add a narrow, documented alias in `scripts/epg_coverage.py`; do not merge identities based on a loose name match.
- Candidate aliases are accepted only when one of the configured XMLTV sources contains the exact candidate ID. Catalogue IDs establish channel identity, not that a schedule is currently available.
- Indian Bangla channels retain a single primary EPG source ID to reduce the risk of mixing schedules from different feeds.
- Do not infer Bangladesh channel schedules from similarly named Indian channels. Add local mappings only after confirming a genuine Bangladesh listing source.
- Backup, Test, Not Playing, New Backup, and New Channels groups are excluded from active mapping coverage.
- Mapping coverage is not stream-health coverage. `MAPPED` means at least one configured source has current/future programme data; it does not guarantee that the live stream works.

## Catalogue reference

The DishTV channel catalogue maintained in [iptv-org/epg](https://github.com/iptv-org/epg/blob/335458005387e07417a98399eb423c78d62a3bd9/sites/dishtv.in/dishtv.in.channels.xml) is used to verify selected Indian channel aliases, including ABP Ananda, CTVN AKD Plus, TV9 Bangla, Republic Bangla, Anmol Cinema, The Q, and other listed services. The generator still checks configured XMLTV feeds for usable programme data before reporting live/future coverage.

## Programme-data permissions

**Automated retrieval and public redistribution rights for the configured programme-data sources have not been established.** Public accessibility of a feed, an open-source generator licence, and catalogue identity evidence do not by themselves grant permission to republish programme schedules. Obtain provider terms or written permission that covers automated retrieval and public XMLTV redistribution, or switch to a properly licensed source before treating public publication as approved. Do not mark any source policy approval fields true without supporting evidence.
